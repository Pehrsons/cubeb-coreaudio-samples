Dump to WAV
32-bit float is exactly what the page received: no scaling, no clipping above full scale, no dither, so a level measured from the file matches the one measured live. The recording is held in memory until stopped, at about 11 MB per minute per channel, and downloads when stopped. The filename and a comment inside the file record the browser, the constraints and the rate.
